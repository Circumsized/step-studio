## 阻塞变更记录（2026-11-13 实查）

**M5.2 的更新流程从「缺接线」改判为「缺 HTTP 客户端」**——这不是接线问题。

壳侧要完成 check（拉索引 → 验签 → 比版本 → 提示）需要发 HTTPS 请求。查证：

- 树里有 `hyper`，但它是 wry/tao 的传递依赖，不是壳能直接用的稳定 API
- 没有 `reqwest` / `tauri-plugin-http`
- 加 `reqwest` 约 40 个传递包，且要把整套 `fetchUpdateIndex` 的拉取-验签逻辑
  （readBounded / AbortSignal / mirror / canary 发现）移植到 Rust

**判断：记缺口，不硬造。** 更新是发布面功能，不是壳的核心；为一个尚未有发布源的
功能引入 40 个包不划算。方案 §12.4 的更新验收本身也要求真机（「升级中 daemon 在跑、
降级攻击、迁移后凭据可用、回滚后数据完好，各一个真机用例」），卡 B1。

**已就绪的部分**（等 HTTP 客户端即可接线）：`swap.rs`（换包）、`upgrade.rs`（升级标记）、
`update-index.ts` 的索引解析与验签逻辑（可作为 Rust 移植的参照）、`signing.rs` 的单产物签名。

## B2 解除记录（2026-11-14）

用户指令「那你安装 step code cli 然后进行测试呀」。Runtime 装上了——`omp-patch/vendor/oh-my-pi`
的 fork 构建出 `omp/18.13.2-studio.10`，经 `~/.local/bin/step` 上 PATH。装的过程中暴露
**四个真实的跨层契约错误**，此前全部被「测试 skip」和「替身自同意」掩盖：

| # | 缺陷 | 后果 |
| --- | --- | --- |
| 1 | `StepRpc::spawn` 传 `--include-live-events`，钉住的 Runtime 没这个 flag，见即 exit 2 | 适配器**根本起不了真 CLI**。报的是 spawn error 不是协议 error，所以每个「真 CLI」测试都 skip 而不是红 |
| 2 | `adapter::hello_result` 手抄 adapter 的身份字段，漏了 `upstreamCommit` | TS 客户端要求该字段，每次握手 `malformed response`。跨语言测试的「非空泛证明」写的正是这个失败签名——所以它自证过，也从没绿过 |
| 3 | 适配器等 `agent_settled` 结算回合，真 CLI 发 `session_settled` | `agent_settled` 在 Runtime 源码里**根本不存在**。没有回合被结算，Host 等到超时，壳停在「streaming」 |
| 4 | `adapter_endpoint` 硬编 `temp_dir()/step-studio-adapter.sock`，而 `--endpoint` 是参数化的 | 两个 daemon（或一个 daemon 加一个上次遗留的 adapter）抢同一个 socket：第二个连上第一个的 adapter，用自己的 epoch serve 别人的 runtime。**重建过的二进制表现和没重建一模一样**，日志里没有任何提示 |

外加三处测试自欺：`crates/step-studio-runtime/tests/fixtures/fake-step.mjs` 跟着适配器一起发
虚构的 `agent_settled`；`packages/studio-host/test/real-runtime-adapter.test.ts` 自己发明了一个
bridge token（daemon 从不读那个文件，token 是固定字面量 `"step-studio"`），并把 `createRequestId`
最后一次返回的值当 prompt id 用（那其实是 snapshot 的 id）。

**修完的结果**：`cargo test -p step-studio-{bridge,runtime,host,sessions,tui}` 全绿（此前 15 个
失败），`packages/studio-host/dist/test/real-runtime-adapter.test.js` 用真 CLI 通过（2.7 s），
`crates/studio-host/tests/daemon.rs` 14 个全过，`cargo clippy --all-targets -D warnings` 干净，
`npm run check` 全绿。

**副作用（需用户知晓）**：本机 `~/.omp/agent/config.yml` 的默认模型从
`autoclaw-cn/zaicoding_glm-5.3`（402 积分不足）改成了 `stepfun-cn/step-3.7-flash`（有额度）。
不改则真实 turn 跑不动。原值备份在 `/tmp/config.yml.bak`。
