# 研发进展表

按 `design/plan.md` §16.3 的逐条范围与验收条件跟踪（§17 已改为指向本目录，不再放表）。
每个里程碑一个文件，记录：范围、验收条件、当前状态、阻塞、下一步。

**规则**（本项目自己的纪律，不是外加的）：

1. 一个里程碑的完成 = 它的**每一条验收条件**都有证据，不是「代码写了」。
2. 「未做」必须写清**卡在什么**，且这个卡点要是可验证的事实（缺真机 / 缺 CLI / 缺人眼），
   不是「还没轮到」。
3. 每次提交推进了某一条，就同一次提交更新对应文件。diff 就是记录。
4. 每周（或每个会话结束）更新 `summary.md` 的总览数字。
